# وضعیت فنی این بسته

## تغییرات موجود در سورس
- رابط Windows Forms و نمودار فعلی حفظ شده‌اند.
- `SoftEtherClientEngine` از `vpncmd.exe` استفاده می‌کند تا حساب اتصال VPN Gate را بسازد/به‌روزرسانی کند و اتصال/قطع را درخواست کند.
- Workflow در GitHub Actions سورس رسمی SoftEther را با submoduleها کامپایل می‌کند و فقط `vpnclient.exe`, `vpncmd.exe`, `hamcore.se2` را به‌عنوان موتور همراه برنامه کپی می‌کند؛ رابط Client Manager و نصب‌کنندهٔ رسمی در بستهٔ خروجی قرار نمی‌گیرند.
- در اولین اتصال، برنامه با UAC helper، موتور را در `%ProgramData%\OpenSSTP\SoftEtherRuntime` قرار می‌دهد، سرویس ویندوز را ثبت/شروع می‌کند و با `vpncmd NicCreate VPN` تلاش می‌کند آداپتور مجازی را بسازد.
- نمودار شمارنده‌های بایت واقعی رابط شبکه را می‌خواند و وقتی اتصال تأیید نشده، مقدار صفر نشان می‌دهد.
- «مرا به خاطر بسپار» رمز را در Windows Credential Manager ذخیره می‌کند.

## محدودیت‌ها و آزمایش‌های باقی‌مانده
- این محیط اجرای Visual Studio/CMake روی Windows یا نصب درایور را انجام نداده؛ بنابراین کد و Workflow هنوز باید در GitHub Actions کامپایل و روی ویندوز آزمایش شوند.
- لازم است تأیید شود که `vpncmd NicCreate VPN` در نسخهٔ ساخته‌شده، سرویس و درایور را بدون خطا ایجاد می‌کند و امضای درایور با نسخهٔ ویندوز سازگار است. UAC لازم است.
- پس از ساخت، اتصال به سرور واقعی VPN Gate، مسیر ترافیک، DNS/route، قطع اتصال و سرعت دانلود/آپلود باید عملاً آزمایش شوند. ساخت موفق به‌تنهایی اثبات اتصال نیست.
- این بسته برنامهٔ رسمی SoftEther VPN Client + VPN Gate Client Plugin را نصب یا همراه خروجی نمی‌آورد؛ فقط موتور سرویس SoftEther و ابزار خط فرمان لازم را توزیع می‌کند.
