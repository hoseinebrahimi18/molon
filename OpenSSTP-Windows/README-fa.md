# Open-SSTP Windows — رابط گرافیکی با موتور SoftEther همراه برنامه

هدف این نسخه حفظ رابط گرافیکی فعلی OpenSSTP و استفاده از موتور واقعی SoftEther برای اتصال به سرورهای سازگار با VPN Gate است؛ بدون نصب برنامهٔ گرافیکی **SoftEther VPN Client + VPN Gate Client Plugin**.

## روش کار

- GitHub Actions سورس رسمی SoftEther را با submoduleهای موردنیاز دریافت و از سورس کامپایل می‌کند.
- فقط فایل‌های موتور `vpnclient.exe`، `vpncmd.exe` و `hamcore.se2` در خروجی OpenSSTP قرار می‌گیرند؛ برنامهٔ Client Manager، نصب‌کنندهٔ رسمی و افزونهٔ رابط کاربری VPN Gate همراه خروجی نیستند.
- هنگام اولین اتصال، OpenSSTP با تأیید Windows UAC فایل‌های موتور را در `%ProgramData%\OpenSSTP\SoftEtherRuntime` قرار می‌دهد، سرویس ویندوز را ثبت/راه‌اندازی می‌کند و با فرمان `vpncmd NicCreate VPN` آداپتور مجازی را ایجاد می‌کند. این نصب فقط برای اجزای سیستمی موتور و آداپتور است، نه نصب رابط گرافیکی کلاینت رسمی.

## اتصال به VPN Gate

1. در `SERVER / HOST` نام میزبان یا IP سرور را وارد کن؛ می‌توانی پورت را هم مشخص کنی، مثلاً `public-vpn.example.net:443`. اگر پورت ننویسی، 443 استفاده می‌شود.
2. برای بسیاری از سرورهای VPN Gate، Hub برابر `VPNGATE` و نام کاربری `vpn` است؛ اطلاعات همان سرور را بررسی کن. رمز عبور بسته به سرور متفاوت است و ممکن است خالی باشد.
3. روی Connect بزن. اولین بار ممکن است Windows اجازهٔ Administrator بخواهد تا سرویس و آداپتور شبکه ایجاد شوند.

این برنامه فهرست سرورهای VPN Gate را از افزونهٔ رسمی نمایش نمی‌دهد؛ در این نسخه، آدرس سرور را کاربر وارد می‌کند.

## نمودار سرعت واقعی

نمودار و سرعت دانلود/آپلود از اختلاف شمارنده‌های واقعی بایت رابط شبکهٔ SoftEther در بازه‌های یک‌ثانیه‌ای محاسبه می‌شوند، نه از اعداد تصادفی یا انیمیشن ساختگی. اگر اتصال تأیید نشود یا آداپتور در دسترس نباشد، برنامه سرعت VPN را صفر نشان می‌دهد. این روش ترافیک رابط مجازی را می‌سنجد؛ صحت نهایی آن باید پس از اتصال واقعی روی ویندوز بررسی شود.

## «مرا به خاطر بسپار»

اگر گزینه فعال باشد، رمز عبور در Windows Credential Manager برای کاربر فعلی ویندوز ذخیره می‌شود؛ نام سرور در تنظیمات محلی برنامه نگه‌داری می‌شود. با برداشتن تیک، اطلاعات ذخیره‌شده پاک می‌شوند. این گزینه به‌تنهایی اتصال خودکار ایجاد نمی‌کند.

## ساخت برنامه

1. محتویات ZIP پروژه را در ریشهٔ مخزن GitHub قرار بده، نه اینکه فقط خود ZIP را به مخزن اضافه کنی.
2. به **Actions** برو و Workflow با نام `Build OpenSSTP Windows with bundled SoftEther engine` را اجرا کن.
3. بعد از موفقیت، Artifact با نام `OpenSSTP-Windows-Bundled-SoftEther` را دانلود کن. خروجی شامل `OpenSSTP.Windows.exe` و پوشهٔ `softether-runtime` است؛ این دو را کنار هم نگه دار.

## وضعیت آزمایش

کد bootstrap و Workflow برای این معماری آماده شده‌اند، اما این محیط امکان ساخت ویندوزی، نصب درایور، یا اتصال به سرور زنده VPN Gate را ندارد. بنابراین هنوز نمی‌توان ادعا کرد اتصال نهایی آزمایش شده است. پس از اجرای Workflow باید در ویندوز بررسی شوند: نصب سرویس و آداپتور، اتصال و قطع اتصال، عبور ترافیک، DNS/route و تطابق نمودار با ترافیک واقعی.
